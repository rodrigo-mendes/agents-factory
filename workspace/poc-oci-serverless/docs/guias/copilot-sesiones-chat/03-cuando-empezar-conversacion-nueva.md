# Cuándo conviene empezar una conversación nueva

> ↩ [Guía: sesiones de chat de Copilot](00-guia-sesiones-copilot.md)

En VS Code puedes abrir una conversación nueva en cualquier momento (Ctrl+N / ⌘N), y eso borra todo lo que veníamos hablando antes de un plumazo. Conviene hacerlo cuando:

| Situación | Razón |
|---|---|
| Cambiaste de objetivo | Pasaste de arreglar un bug a crear una función nueva, aunque sea en el mismo proyecto. |
| El chat se fue por las ramas | Prefieres empezar de nuevo con otro enfoque, en vez de seguir parchando algo que ya empezó mal. |
| Te pusiste a trabajar en otra rama o en otra cosa | No tiene nada que ver con lo anterior. |
| Ya cerraste el pull request o lo mergeaste | Esa tarea ya terminó su ciclo. |
| Lo que se habló antes ya no te sirve para lo que vas a preguntar ahora | Mantener abierta una conversación tiene sentido solo si lo de antes ayuda al chat a entender lo de ahora; si no, solo molesta. |

Si estás yendo y viniendo entre dos tareas distintas, mejor tener dos conversaciones abiertas y cambiar entre ellas, en vez de mezclar todo en una sola.
