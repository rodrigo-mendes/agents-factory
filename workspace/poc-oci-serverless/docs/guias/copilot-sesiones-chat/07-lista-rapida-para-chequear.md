# Lista rápida para chequear

> ↩ [Guía: sesiones de chat de Copilot](00-guia-sesiones-copilot.md)

Antes de seguir enviando mensajes, repasa:

- [ ] ¿El mensaje que voy a enviar pide solo una cosa, y está claro?
- [ ] ¿Mostré el archivo o la parte exacta con `#` en lugar de esperar que lo adivine?
- [ ] ¿Las reglas que siempre se repiten están en instrucciones personalizadas, y no las estoy escribiendo a mano cada vez?
- [ ] ¿Revisé la barra de uso antes de seguir enviando mensajes?
- [ ] Si está casi llena: ¿me conviene resumir (si sigo en lo mismo) o empezar de nuevo (si cambié de tema o hay mucho ruido)?
- [ ] Si resumo: ¿dije claramente qué no puede perderse?
- [ ] ¿Veo señales de que algo no va bien (se repite, hay contradicciones, respuestas genéricas) incluso después de resumir?
