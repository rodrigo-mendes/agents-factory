## Decisions needed at G1 (from P1)

1. **quarkus-langchain4j (U8)**: no stable build on Quarkus 3.40.
2. **OpenSpec overlap**: OpenSpec ships its own Claude Code skills/commands, including `/opsx:sync` and `/opsx:verify`, which overlap with the planned `spec-synchronizer` / `/syncing-spec-from-code`. Reuse OpenSpec's commands and wrap them, or keep ours and use only OpenSpec's file format.
3. **SnapStart × native**: they are mutually exclusive (SnapStart has no OS-only runtime support); U1 must present JVM+SnapStart vs native as an ADR choice.
