# provision-oci-serverless-stack

Routes to `@oci-serverless-stack` — the Full-Stack Serverless Deployer that orchestrates end-to-end
creation of OCI Functions + Terraform infrastructure + API Gateway routes in a single coordinated workflow.

## What the agent does

- Reads structured work-order records from `docs/handoff/<capability>/` (generated by `@oci-serverless-architect`).
- Delegates Java function implementation to `@oci-functions-java` (Stream A).
- Delegates Terraform networking + IAM to `@oci-terraform` (Stream B — parallel with Stream A).
- Waits for both streams, then delegates Terraform integration resources (Function resource, API Gateway route) to `@oci-terraform` (Stream C — sequential).
- Validates the result: `mvn compile`, `terraform fmt -check`, `terraform validate`, `scripts/preflight.sh`.

## Parallel delegation model

```
Stream A (Java)                    Stream B (Terraform)
─────────────────                  ─────────────────────
@oci-functions-java:               @oci-terraform:
 • Handler class                    • Networking (VCN, subnet)
 • Model classes                    • IAM (dynamic groups, policies)
 • pom.xml dependencies
 • func.yaml config
         │                                   │
         └──────── synchronization ──────────┘
                         │
              Sequential (depends on both):
              @oci-terraform:
               • Function resource (needs func.yaml)
               • API Gateway route (needs function OCID)
```

## Pre-requisites

The handoff directory `docs/handoff/<capability>/` must contain:
- `stream-a-java.md` — Java function work-order
- `stream-b-terraform-infra.md` — independent Terraform work-order
- `stream-c-terraform-integration.md` — dependent Terraform work-order

These are produced by `/design-oci-architecture` (`@oci-serverless-architect`).

## Incremental addition mode

Use this agent with the argument of an existing capability when adding a function to an existing Application (`Stream D` workflow — additive only, no destroy operations).
