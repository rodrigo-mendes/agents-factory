## Version-lifetime risk

As of 2026-10-30.

- Next.js 16.4.0 shipped on 07 Oct and 16.4.3 on 23 Oct (the year is not shown on the releases page; 2026 by order). The line is new; re-read the upgrade guide before moving the pin. Source: https://github.com/vercel/next.js/releases
- Turbopack is the default for `next build` and a custom `webpack` config fails the build; a plugin that adds one breaks the pipeline at upgrade. Source: https://nextjs.org/docs/app/guides/upgrading/version-16
- Pinned SHAs (setup-node v7.1.0, checkout v7.0.1, cache v6.1.0, pnpm/action-setup v6.1.0, upload-artifact v7.0.2, download-artifact v8.0.2, configure-aws-credentials v6.3.0) were resolved on 2026-10-30; re-run `git ls-remote` before bumping. Source: https://github.com/actions/setup-node/releases
- The official with-docker example pins `NODE_VERSION=24.13.0-slim`, older than the current 24 line; set the tag from the current LTS. Source: https://github.com/vercel/next.js/tree/v16.4.3/examples/with-docker
- Vercel CLI has no pin; `@latest` moves under the pipeline. Source: https://vercel.com/kb/guide/how-can-i-use-github-actions-with-vercel
