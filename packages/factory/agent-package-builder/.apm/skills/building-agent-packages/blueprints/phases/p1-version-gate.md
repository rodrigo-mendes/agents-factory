# P1 Version gate

Back to [SKILL.md](../../SKILL.md).

1. For every framework, fetch the official release/support page (WebFetch). Record version, release date, support/EOL status, source URL.
2. No version given -> propose the current stable/LTS and say so.
3. Target EOL or not current -> list alternatives with dates; do not choose silently.
4. Anything not resolvable from an official page is `(unverified)`.

**Done when:** each framework has a verified target version row. **Gate:** feeds G1.
