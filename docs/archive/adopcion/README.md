# Programa de Adopción Copilot — ECI

Guías para equipos de desarrollo que usan GitHub Copilot con agentes customizados en El Corte Inglés.

Esta colección cubre tres perfiles:

- **Dev** — desarrolladores que usan Copilot día a día
- **Tech Lead** — responsables de configurar el ecosistema Copilot del equipo
- **Gobierno ECI** — equipo que administra el programa y los artefatos globales
