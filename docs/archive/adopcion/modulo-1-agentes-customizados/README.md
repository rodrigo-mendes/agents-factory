## Resumen rápido

| Pregunta | Respuesta corta |
|---|---|
| ¿Cómo invoco un agente? | Escribe `@nombre-del-agente` en el chat o selecciónalo en el panel de chat mode. |
| ¿Qué diferencia hay con el chat normal? | El agente sigue un proceso estructurado y verifica las convenciones ECI antes de generar código. |
| ¿Por qué el agente pide confirmación en medio de la tarea? | Llega a la fase P3 (Proponer). Es normal; debes confirmar para continuar. |
| ¿Qué hago si el agente genera algo incorrecto? | Interrumpe, corrige el prompt y relanza. Ver guía 1.4. |
| ¿Qué agentes hay disponibles? | Ver catálogo en guía 1.5. |
