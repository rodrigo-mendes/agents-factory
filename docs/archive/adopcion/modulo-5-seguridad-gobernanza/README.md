## Resumen rápido

| Regla | Descripción |
|---|---|
| Nunca compartas secretos | Credenciales, tokens, claves de API, contraseñas: jamás en el chat |
| Revisa siempre el código generado | Copilot comete errores; la responsabilidad del código es del desarrollador |
| Cuidado con el código de terceros | Copilot puede sugerir fragmentos con licencias incompatibles |
| La aprobación final es tuya | Copilot no puede aprobar un PR ni validar requisitos de negocio |
