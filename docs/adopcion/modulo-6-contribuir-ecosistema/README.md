## Cuándo contribuir

| Situación | Acción recomendada |
|---|---|
| Usas Copilot para una tarea y siempre tienes que explicar las mismas convenciones | Solicitar una skill o instrucciones de contexto |
| Un agente genera código incorrecto consistentemente para un tipo de tarea | Reportar el problema (puede requerir actualizar la skill) |
| Tu equipo tiene un flujo de trabajo repetitivo complejo que podría automatizarse | Solicitar un nuevo agente |
| Una skill usa patrones que ya no son los correctos para la versión actual del framework | Reportar para deprecación/actualización |
