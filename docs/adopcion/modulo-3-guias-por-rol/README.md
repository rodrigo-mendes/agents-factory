## Cómo usar estas guías

Cada guía es independiente. Ve directamente a la de tu rol principal. Si trabajas en múltiples dominios (backend + infra, por ejemplo), lee las dos.

Todas las guías comparten la misma estructura:
- Casos de uso más frecuentes con prompts de ejemplo
- Qué agente/modo usar para cada caso
- Errores comunes a evitar
