## Resumen rápido

|---|---|
| ¿Qué modos tiene Copilot? | Ask (preguntas), Edit (edición de archivos), Agent (tareas multi-paso). |
| ¿Qué agentes hay en ECI? | Ver mapa del ecosistema y catálogo del Módulo 1. |
| ¿Qué necesito instalar? | VS Code reciente + extensión GitHub Copilot Chat ≥ 0.20 + plan activo. |
| ¿Copilot reemplaza el code review? | No. La responsabilidad del código generado es siempre tuya. Ver Módulo 5. |
