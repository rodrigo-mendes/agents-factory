## Resumo rápido

| Pergunta | Resposta curta |
|---|---|
| Que modos o Claude Code tem? | Exploração/Plan Mode (perguntar e planejar), Edições diretas (edição de arquivos com diff) e Modo agente (tarefas multi-passo, que é o padrão). |
| Como abordar uma tarefa? | **Planeje antes de executar:** Plan Mode (`Shift+Tab`) para propor um plano → revise → execute. |
| Que agentes existem na BRX? | Ver mapa do ecossistema e catálogo do Módulo 1. |
| O que preciso instalar? | Claude Code (CLI `claude` no terminal) + extensão do IDE (VS Code/JetBrains, opcional) + conta Anthropic com plano corporativo ativo. |
| O Claude Code substitui o code review? | Não. A responsabilidade pelo código gerado é sempre sua. Ver Módulo 5. |
