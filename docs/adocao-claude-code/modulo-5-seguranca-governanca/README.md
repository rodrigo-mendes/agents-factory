## Resumo rápido

| Regra | Descrição |
|---|---|
| Nunca compartilhe segredos | Credenciais, tokens, chaves de API, senhas: jamais no prompt |
| Revise sempre o código gerado | O Claude comete erros; a responsabilidade do código é do desenvolvedor |
| Cuidado com código de terceiros | O Claude pode reproduzir trechos com licenças incompatíveis |
| A aprovação final é sua | O Claude não pode aprovar um PR nem validar requisitos de negócio |
