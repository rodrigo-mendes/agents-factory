# Módulo 6 — Contribuir ao Ecossistema BRX

**Perfil:** Dev avançado / Tech Lead / Equipe de Governança BRX  
**Pré-requisito:** [Módulo 1](../modulo-1-agentes-customizados/README.md), [Módulo 4](../modulo-4-instrucoes-contexto/README.md)

Este módulo é para quem quer **ampliar** o ecossistema: solicitar novos subagentes ou skills, entender o ciclo de vida de uma skill, ou aprender quando revisar e atualizar um subagente existente.

## Quando contribuir

| Situação | Ação recomendada |
|---|---|
| Você usa o Claude Code para uma tarefa e sempre precisa explicar as mesmas convenções | Solicitar uma skill ou instruções de contexto |
| Um subagente gera código incorreto consistentemente para um tipo de tarefa | Reportar o problema (pode exigir atualizar a skill) |
| Sua equipe tem um fluxo de trabalho repetitivo e complexo que poderia ser automatizado | Solicitar um novo subagente |
| Uma skill usa padrões que já não são os corretos para a versão atual do framework | Reportar para depreciação/atualização |
