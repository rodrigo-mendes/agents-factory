## Como usar estes guias

Cada guia é independente. Vá direto ao do seu papel principal. Se você trabalha em múltiplos domínios (backend + infra, por exemplo), leia os dois.

Todos os guias compartilham a mesma estrutura:
- Casos de uso mais frequentes com prompts de exemplo
- Qual subagente/modo usar para cada caso
- Erros comuns a evitar
