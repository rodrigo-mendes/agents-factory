## Function

Runs the `book-orchestrator` in `mode=enrich-chapter`. Takes an existing `chapter.md` written outside the pipeline (without `[CODE:]` / `[DIAGRAM:]` markers), infers injection points using heuristic rules, writes an enriched `prose.md`, then runs the standard P4.2+P4.3 sub-pipeline to generate all chapter assets and produce a fully assembled `chapter.md`.

1. **Loads heuristics:** reads `book-agent/.claude/skills/enriching-book-chapter/blueprints/injection-heuristics.md`
2. **Optionally loads TOC context:** if `toc=` is provided (or `Books/{slug}/toc.md` exists), reads chapter objective and key concepts for better marker descriptions
3. **Enriches prose:** spawns `chapter-enricher` → writes `Books/{slug}/chapters/ch{N:02d}/prose.md` with `[CODE:]` and `[DIAGRAM:]` markers inserted, original prose preserved verbatim
4. **Runs P4.2 in parallel:** spawns `code-illustrator`, `diagram-illustrator`, `expert-reviewer`, `skeptic-reviewer`
5. **Runs P4.2b (optional):** spawns `code-validator` unless `code_style=pseudocode-only`
6. **Runs P4.3:** spawns `chapter-assembler` → `chapter.md`

## Prerequisites

- The external `chapter.md` must exist and be readable
- `slug=` is always required (determines the output directory `Books/{slug}/`)
- `Books/{slug}/` does not need to exist — it will be created

## Input Parameters

| Parameter | Required | Default | Notes |
|-----------|----------|---------|-------|
| `chapter.md path` | ✅ | — | First positional argument — path to external chapter.md |
| `slug` | ✅ | — | Output book folder under `Books/` |
| `chapter` | ⚠️ | `1` | Chapter slot number (integer). Determines `ch{N:02d}/` subfolder |
| `toc` | ⚠️ | auto | Path to `toc.md` for context. Defaults to `Books/{slug}/toc.md` if it exists |
| `audience` | ⚠️ | inferred | Target reader profile. Used by expert-reviewer and skeptic-reviewer |
| `code_style` | ⚠️ | `working-code` | `pseudocode-only` / `working-code` / `pseudocode-first` |
| `code_language` | ⚠️ | `pseudocode` | Primary code language for code-illustrator |
| `additional_languages` | ⚠️ | _(none)_ | Extra code languages, comma-separated. Requires `code_style` ≠ `pseudocode-only` |

## Output

Writes to `Books/{slug}/chapters/ch{N:02d}/`:
```
Books/{slug}/chapters/ch{N:02d}/
├── prose.md           (enriched — original prose + [CODE:]/[DIAGRAM:] markers)
├── code.md            (generated by code-illustrator)
├── diagrams.md        (generated by diagram-illustrator)
├── expert_notes.md    (generated by expert-reviewer)
├── skeptic_notes.md   (generated by skeptic-reviewer)
└── chapter.md         (assembled by chapter-assembler)
```

`book.md`, translations, and EPUBs are NOT automatically updated — run `/writing-technical-book` from P5 onward to regenerate them.

## Usage

```
/enriching-book-chapter draft-chapters/intro.md slug=my-book chapter=1
/enriching-book-chapter external/ch03.md slug=event-driven-arch chapter=3 toc=Books/event-driven-arch/toc.md audience="senior backend engineers"
/enriching-book-chapter raw/chapter-five.md slug=kafka-internals chapter=5 code_style=working-code code_language=java
```
