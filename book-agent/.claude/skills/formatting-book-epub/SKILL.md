## Function

Routes directly to `book-formatter`. Generates the EPUB 3.0 source tree for one language, then the orchestrator zips it.

**Format:** EPUB 3.0 reflowable (Amazon KDP recommended format, 2025–2026). MOBI is deprecated since March 2025.

**Generated files:**
```
Books/{slug}/kindle/{language}/epub-src/
├── mimetype
├── META-INF/container.xml
└── OEBPS/
    ├── content.opf
    ├── nav.xhtml
    ├── toc.ncx
    ├── styles.css
    └── ch{N:02d}.xhtml  (one per chapter)

Books/{slug}/kindle/{language}/book.epub  ← final zipped EPUB
```

**Mermaid diagrams** are converted to a text caption + preserved source `<pre>` block (Kindle cannot render Mermaid).

**Code blocks** are HTML-escaped and wrapped in `<pre><code>` with monospace styling.

## Input Parameters

| Parameter | Required | Default | Notes |
|-----------|----------|---------|-------|
| `book_path` | ✅ | — | Absolute or relative path to `book.md` |
| `slug` | ⚠️ | derived from path | Output directory name under `Books/` |
| `toc` | ⚠️ | `Books/{slug}/toc.md` | Path to `toc.md` for navigation generation |
| `language` | ⚠️ | `en` | `en`, `pt-BR`, or `es` |
| `author` | ⚠️ | `Author Name` | Book author for EPUB metadata |

## Usage

```
/formatting-book-epub Books/distributed-systems/book.md slug=distributed-systems language=en author="Jane Doe"
/formatting-book-epub Books/distributed-systems/book_pt-BR.md slug=distributed-systems language=pt-BR
```

## After Running

Upload the generated `.epub` to Amazon KDP:
1. Go to kdp.amazon.com → Bookshelf → Add New Title → eBook
2. Upload `Books/{slug}/kindle/{language}/book.epub`
3. Validate with Kindle Previewer (free tool from Amazon) before submitting
4. Note: cover image (2560×1600 px min) must be provided separately — not generated by this skill
