## Function

Routes to `epub-repairer`. Validates one or more `.epub` files against the EPUB 3.0 / ZIP spec, then repairs any that fail by repacking from the `epub-src/` source tree.

**What it checks:**

| Check | Requirement |
|-------|------------|
| ZIP integrity | File is a valid ZIP archive |
| mimetype placement | `mimetype` is the first entry in the ZIP |
| mimetype compression | `mimetype` is `ZIP_STORED` (uncompressed) |
| Forward-slash paths | No backslash (`\`) in any archive entry name |
| `container.xml` | `META-INF/container.xml` accessible with forward-slash key |
| XHTML well-formedness | All `.xhtml` files parse as valid XML (catches unescaped `<` in code blocks) |

**How it repairs:**

- If `epub-src/` exists alongside the `.epub`: repacks using `blueprints/build-epub.py` (forward-slash `ZipInfo`, `mimetype` first and `ZIP_STORED`, deterministic sort).
- If no `epub-src/`: extracts the broken `.epub` in-memory, normalizes paths, and repacks — handling the path-separator issue without needing the source tree.

**Blueprint scripts (single source of truth):**

| Script | Role |
|--------|------|
| `blueprints/build-epub.py` | `build_epub(src_dir, out_path)` — canonical packer; CLI: `python build-epub.py <src> <out>` |
| `blueprints/validate-epub.py` | EPUB structure validator; CLI: `python validate-epub.py <epub> [...]`; exits 1 on any FAIL |

## Input Parameters

| Parameter | Required | Default | Notes |
|-----------|----------|---------|-------|
| `path` | ✅ | — | `kindle/` directory (checks all 3 languages) or a single `book.epub` path |
| `languages` | ⚠️ | `en,pt-BR,es` | Comma-separated filter when path is a `kindle/` dir |

## Usage

```
# Validate and repair all 3 EPUBs for a book
/repairing-book-epub Books/my-book/kindle/

# Validate and repair only the English EPUB
/repairing-book-epub Books/my-book/kindle/ languages=en

# Target a single file
/repairing-book-epub Books/my-book/kindle/pt-BR/book.epub
```

## After Running

Re-validate with Kindle Previewer (free, from Amazon) before uploading to KDP:
1. Open Kindle Previewer → File → Open Book → select `book.epub`
2. If it opens cleanly: upload at kdp.amazon.com → Bookshelf → eBook → Manuscript
