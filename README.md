# Agents Factory

Agents Factory is a set of **Skills, Subagents and Rules for Claude Code**, built around one idea:
AI agents should not invent facts. Every artifact is grounded in official documentation, pinned to
a version, and checked by a quality loop before it is used.

- **Source of truth:** `packages/` (APM packages). **Generated output:** `.claude/`, produced by
  `apm install --target claude`. Edit `packages/`, then regenerate. See
  [Maintaining the docs](docs/reference/maintaining-docs.md) for the full regeneration steps.
- **Documentation:** start at [docs/README.md](docs/README.md).

## Principles

| Principle | Meaning |
|---|---|
| **Version absolutism** | One skill is one version. Old versions are treated as misinformation. |
| **Source hierarchy** | Official docs first, then official blogs and examples, then verified community sources. Sources older than 12 months are rejected unless they are still the current stable release. |
| **Executable truth** | Every claim links to a dated official source. Without one, it is marked *unverified*. |
| **Three-tier rules** | ✅ always do · ⚠️ ask first · 🚫 never do (with the alternative). |
| **P0–P5 workflow** | Verify docs → analyze → consult → propose → implement → validate. |

## Quick start

Run these in Claude Code from the repository root:

```
/researching-technical-frameworks FastAPI 0.115
```
Researches one technology with source checks and version pinning.

```
/skill-best-practices-validator .claude/skills/
```
Validates the quality of skills against the conventions.

```
/audit-cc-architecture-consensus .claude/
```
Runs a three-lens architecture audit of a Claude Code project and returns one prioritized report.

For the full list of entry points, see [docs/entry-points/README.md](docs/entry-points/README.md).

## Repository layout

```
packages/     source of truth: 44 APM packages in family folders + 19 sales bundles
.claude/      generated: skills, subagents, rules used by Claude Code (committed)
scripts/      post-install fixups, bundle export, documentation catalog generator
docs/         documentation (start at docs/README.md)
workspace/    research outputs and validation files (versioned)
apm.yml       root manifest that aggregates the packages
```
